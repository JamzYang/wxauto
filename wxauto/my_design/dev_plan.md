## M1（PoC，~1周）：基础可达性与链路打通

### PT-M1-1 UIA 适配器最小实现（可测试）
- [ ] ST-1.1 会话未读检测（红点/数字/加粗，优先 UIA）
- [ ] ST-1.2 进入会话与消息区读取（未读区间最近 N 条，默认 20，可配）
- [ ] ST-1.3 输入框写入与发送按钮点击
- [ ] ST-1.4 有限 @：候选浮层定位与精确匹配（白名单成员子集）
- [ ] ST-1.5 失败回退：只读模式切换与指数退避（最小实现）
- [ ] ST-1.T 测试与验收：冒烟脚本覆盖“会话列表/消息区/输入框/发送/@浮层”的可达性；失败自动记录审计

### PT-M1-2 云端客户端与 DTO（可测试）
- [ ] ST-2.1 定义 Pydantic 模型：AgentRegister/Heartbeat、MessageIngest、MessageReply
- [ ] ST-2.2 HTTP 客户端（httpx）与重试（tenacity，指数退避）
- [ ] ST-2.3 接口打通：/agents/register、/agents/heartbeat、/messages/ingest、/messages/replies
- [ ] ST-2.4 trace_id 生成与透传，对齐云端（优先使用云端下发）
- [ ] ST-2.T 测试与验收：本地假服务或 Postman/Mock 校验 2xx/5xx/超时重试与幂等行为

### PT-M1-3 本地存储与幂等（可测试）
- [ ] ST-3.1 初始化 SQLite：conversations、messages_idempotency 表
- [ ] ST-3.2 文本/语音（转写/元信息）幂等键生成与去重
- [ ] ST-3.3 last_processed_ts 管理与“未读区间最近 N 条”读取推进
- [ ] ST-3.T 测试与验收：单元测试覆盖幂等键生成、重复消息不重复上报、偏移推进正确性

### PT-M1-4 托盘与运行模式控制（可测试）
- [ ] ST-4.1 托盘菜单：显示当前模式（只读/读写/暂停/紧急停用）
- [ ] ST-4.2 操作：一键暂停/紧急停用、打开日志目录
- [ ] ST-4.3 状态持久化与恢复（可选）
- [ ] ST-4.T 测试与验收：手动/自动化验证模式切换对主循环行为的影响

### PT-M1-5 冒烟用例与端到端最小闭环（可测试）
- [ ] ST-5.1 启动后 ≤10s 冒烟检查并记录审计（可达性失败则只读）
- [ ] ST-5.2 白名单群读取→上报→拉取回复→（有限 @）发送→审计
- [ ] ST-5.T 测试与验收：演示端到端最小闭环，导出日志/审计样例

## M2（MVP，~1周）：稳定发言、OCR 兜底与护栏完善

### PT-M2-1 稳定 @ 与三段式回退（可测试）
- [ ] ST-1.1 UIA 候选精确匹配（白名单/别名映射）
- [ ] ST-1.2 失败回退“纯文本 @姓名”（可配置发前确认）
- [ ] ST-1.3 仍高风险：无 @ 发送 + 审计标注与提示
- [ ] ST-1.T 测试与验收：构造命中/失败样例，验证三段式与白名单强校验

### PT-M2-2 OCR 兜底流水线（可测试）
- [ ] ST-2.1 触发条件：UIA 读取失败或低置信
- [ ] ST-2.2 局部截图（mss），尺寸限制与图像预处理
- [ ] ST-2.3 rapidocr-onnxruntime 集成与阈值治理
- [ ] ST-2.4 频控：单会话/全局最小间隔，每分钟上限
- [ ] ST-2.T 测试与验收：模拟 UIA 失败，验证 OCR 回退、频控与置信度降级路径

### PT-M2-3 活动感知与只读切换（可测试）
- [ ] ST-3.1 前台窗口/输入活跃/焦点变更检测
- [ ] ST-3.2 命中活动→本轮只读；下一轮指数退避（2→4→8s）
- [ ] ST-3.3 前台占用预算 ≤ 500ms 并即时还原焦点
- [ ] ST-3.T 测试与验收：人机并发测试脚本（主动打断/输入），验证只读切换与恢复

### PT-M2-4 策略/限流与夜间静默（可测试）
- [ ] ST-4.1 白名单群与 @ 白名单强校验（非白名单阻断/确认）
- [ ] ST-4.2 速率限制：每群最小间隔、全局上限
- [ ] ST-4.3 夜间静默（本地时区），节假日白/黑名单
- [ ] ST-4.T 测试与验收：构造高频/夜间/非白名单场景，验证策略生效

### PT-M2-5 审计、黑匣子与全链路追踪（可测试）
- [ ] ST-5.1 审计：前100字摘要、@目标、结果状态、trace_id；脱敏
- [ ] ST-5.2 黑匣子：控件快照、局部截图（频控）、错误栈、操作序列；本地加密与受控导出
- [ ] ST-5.3 追踪：统一 trace_id 贯穿，与云端对齐
- [ ] ST-5.T 测试与验收：生成成功/失败案例，检查审计/黑匣子/trace 字段完整性与脱敏规则

### PT-M2-6 指标与可观测性（可测试）
- [ ] ST-6.1 指标：uia.locate.qps/success_rate、ocr.trigger.rate/confidence.avg、ingest.qps、reply.send.success_rate、read_only.switch.count 等
- [ ] ST-6.2 日志结构化字段与分级
- [ ] ST-6.T 测试与验收：压测/回放样本，验证关键指标有值且随场景变化

- [ ] ST-1.T 测试与验收：A/B 对比实验，命中率/失败率显著优化

### PT-M3-2 配置中心与热更新（可测试）
- [ ] ST-2.1 本地配置结构与版本管理（selectors/policies/ocr/limits）
- [ ] ST-2.2 云端拉取与本地持久化、回滚
- [ ] ST-2.3 生效机制与安全控制（签名/白名单）

### PT-M3-3 服务化与自动更新（可测试）
- [ ] ST-3.1 以 Windows Service 运行（可选）
- [ ] ST-3.2 自动更新通道与签名校验
- [ ] ST-3.T 测试与验收：安装/升级/回滚流程演练，失败可恢复

### PT-M3-4 监控与告警、Runbook（可测试）

- [ ] ST-4.2 告警规则与阈值治理
